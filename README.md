# 백귀행 (百鬼行)

> "바리데기의 그림자가 봉인된 신령들을 이끌고 옥새를 찾아 서울로 진군한다"

2D 사이드스크롤 액션 로그라이트. [요구명세서 v1.0](SPEC.md)의 콘텐츠 전체를 구현한 **브라우저 실행 빌드**입니다.
의존성 없이 HTML5 Canvas + WebAudio만으로 동작합니다.

## 실행 방법

```bash
# 방법 1: 브라우저로 index.html 열기 (더블클릭)
# 방법 2: 로컬 서버
python3 -m http.server 8000
# → http://localhost:8000
```

## 조작

| 동작 | 키 |
|---|---|
| 이동 | ← → / A D |
| 점프 (2단) | SPACE |
| 대시 (무적 0.2s) | SHIFT |
| 공격 (3타 콤보) | J |
| 강공격 (차지 0.4s) | K (홀드) |
| 특수 / 부적 투척 | L |
| 빙의 스왑 | Q / E (다시 누르면 바리 복귀) |
| 소비품 | 1 2 3 |
| 상호작용 (문·상자·상점) | ↑ 또는 F |
| 일시정지 | ESC |

모바일: 터치 시 가상 버튼 표시 (10.2)
